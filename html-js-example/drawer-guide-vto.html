VTO Integration Guide

Required Iframe Dimensions

Strongly recommended to prevent UI inconsistencies and incorrect breakpoint triggering.

Embedded Integration

Desktop

  • Width: 1200px
  • Height: 720px

Mobile

  • Width: 100%
  • Height: 768px

Modal Integration

Desktop Modal

  • Width: 1160px
  • Height: 700px

Tablet & Mobile Fullscreen

  • Width: 100%
  • Height: 100dvh

Breakpoints

UI automatically adapts based on iframe width:

  • Desktop: 1135px and above
  • Tablet: 701px – 1134px
  • Mobile: 700px and below

Critical Warning

Iframe dimensions directly determine UI rendering. Deviating from recommended dimensions may cause unexpected breakpoint switching, component overlap, and layout issues.

Integration Types

Landing Page Integration

Presents all products associated with the project. VTO plugin retrieves all project data and renders a catalog.

Product Detail Integration

VTO plugin exclusively serves a specific product. Retrieves data only for the relevant product.

Camera Permission

Always include camera permission in iframe:

<iframe allow="camera *;" src="..."></iframe>

Overlay Integration Patterns

Desktop Modal (≥1135px)

Display in centered modal/popup overlay. Provides focused experience while maintaining context. Include close button for easy dismissal.

Tablet & Mobile Fullscreen (≤1134px)

Fullscreen overlay recommended to maximize screen space. Iframe should occupy 100% viewport with body scroll locked. Include close button or gesture.

SDK Integration

Load SDK script for event handling and actions:

<script src="https://cdn.jsdelivr.net/npm/@pulpoar/plugin-sdk@latest/dist/index.iife.js"></script>

Use the Events & Actions drawer to monitor 27 SDK events and control plugin behavior with 9 SDK actions.
